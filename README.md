# 🚗 AutoRent Front-End

Interface web do sistema **AutoRent**, desenvolvida com **React** e **Vite** para gerenciamento de aluguel de veículos.

## 📋 Pré-requisitos

Antes de iniciar o projeto, é necessário possuir instalado:

- Node.js (versão 20 ou superior)
- npm (instalado juntamente com o Node.js)

Verifique as versões:

```bash
node -v
npm -v
```

---

## 🚀 Instalação

Clone o repositório:

```bash
git clone https://github.com/miguelgarbo/auto_rent_front_end.git
```

Acesse a pasta do projeto:

```bash
cd auto_rent_front_end
```

Instale as dependências:

```bash
npm install
```

---

## ▶️ Executando o projeto

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Após iniciar, o Vite exibirá um endereço semelhante a:

```
http://localhost:5173
```

Abra essa URL no navegador.

---

## 📦 Scripts disponíveis

### Executar em modo de desenvolvimento

```bash
npm run dev
```

### Gerar a versão de produção

```bash
npm run build
```

### Visualizar a versão de produção

```bash
npm run preview
```

### Executar o ESLint

```bash
npm run lint
```
